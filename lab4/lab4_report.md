## LLM 部署相关的性能指标列表

|  指标  |   合理性  |
| ----- | ----- |
| 首 Token 返回延迟 | 反应了模型部署推理参数的速度，同时能够直观体现相应速度 |
| 输出 Token 速度（Tokens/s） | 最直接体现模型推理的软件优化效率，各维度的并发的处理能力，硬件性能等 |
| 显存占用率与峰值占用 | 这项指标影响硬件成本，同时容易形成推理瓶颈，当显存占用过高时也会影响推理性能 |
| 错误率 | 从显存报错到驱动、调度器、编解码器等，任何一个错误都可能使推理意外终止，错误率也会影响推理的性能 |
| 并发吞吐量 | 可以稳定同时服务的用户数量也可以体现模型部署的性能，吞吐量越高部署的模型服务器可以支持更高的负载 |

### 单机部署

通过 `homebrew` 下载 `llama.cpp` 后可直接在命令行输入 `llama-cli`、`llama-run`、`llama-simple` 指令。

在选择模型的时候，从`Hugging Face` 选择模型最好选择 `GGUF` 版本的，否则还需要使用 `llama.cpp` 提供的工具将格式转换为 `GGUF` 格式。
